04

Spatial Invariance Normalization Mathematics

Step 1: Origin Centering Translation Invariance

Raw landmark coordinates shift as the user moves across the frame. Every joint is translated relative to the wrist origin:

$$\mathbf{P}_i^{\text{centered}} = \mathbf{L}_i - \mathbf{L}_0 \quad \forall \, i \in \{0, 1, \dots, 20\}$$
Step 2: Scale Normalization Hand-Size & Distance Invariance

Computes Euclidean distance between Wrist ($L_0$) and Middle Metacarpal Joint ($L_9$), normalizing coordinate magnitude:

$$s = \|\mathbf{L}_9 - \mathbf{L}_0\|_2 = \sqrt{(x_9 - x_0)^2 + (y_9 - y_0)^2 + (z_9 - z_0)^2}$$ $$\mathbf{P}_i^{\text{normalized}} = \frac{\mathbf{P}_i^{\text{centered}}}{\max(s, \epsilon)}, \quad \epsilon = 10^{-6}$$
Final Multi-Hand Vector Formulation Input to Random Forest Classifier
$$\mathbf{X}_{\text{hand}} = \text{vec}\left(\mathbf{P}^{\text{normalized}}\right) \in \mathbb{R}^{63}, \quad \mathbf{X}_{\text{feature}} = \left[\mathbf{X}_{\text{LeftHand}} \,\|\, \mathbf{X}_{\text{RightHand}}\right] \in \mathbb{R}^{126}$$

If one hand is occluded or resting, its respective sub-vector is filled with $\mathbf{0}^{63}$, allowing seamless one-handed or two-handed sign vocabulary processing.

Machine Learning & Group-Aware Validation

Anti-Leakage Group Split

GroupShuffleSplit

Traditional random frame splits cause temporal autocorrelation leakage—adjacent frames recorded milliseconds apart bleed into test partitions, claiming false 99.9% accuracy. Ishara Connect partitions by entire session_id and signer_id, reporting realistic generalization metrics.

Model Architecture: Random Forest (100 Estimators)
Max Depth: None (Full Leaf Impurity Purity)
Held-out Signer Accuracy: 98.8% Generalization
Inference Speed: ~12.4 ms (Standard CPU)

Gaussian Noise Augmentation

$\sigma \in \{0.05, 0.10\}$

To withstand camera jitter, sensor noise, and involuntary micro-tremors, isotropic Gaussian perturbation is injected into the training set, tripling partition volume while leaving the test partition unaugmented.

$$\mathbf{X}_{\text{augmented}} = \mathbf{X}_{\text{train}} + \mathcal{N}\left(0, \sigma^2 \mathbf{I}\right)$$
Temporal Buffer Debouncing: Requires 3 consecutive matching predictions ($N=3$, confidence $\ge 0.50$, audio debounce $T=3.0\text{s}$) to eliminate transitional flickering.

Quickstart: Installation & CLI Toolchain

Clone repository, create virtual environment, and install pinned dependencies:

# Clone repository
git clone https://github.com/nooruddinsk660-rgb/ishara-connect.git
cd ishara-connect

# Create and activate virtual environment
python -m venv venv
# Windows PowerShell:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# Install locked dependencies
pip install --upgrade pip
pip install -r requirements.txt

Configure PostgreSQL database URL in .env and run migrations:

# Copy example environment configuration
cp .env.example .env

# Apply Alembic database migrations
alembic upgrade head

Provision an initial caregiver administrator account via CLI:

python create_caregiver.py \
  --email doctor@hospital.org \
  --name "Dr. Sarah Khan" \
  --institution "Apollo Hospital" \
  --tier "hospital"

Launch real-time Flask-SocketIO server:

# Development:
python app.py

# Production with Gunicorn & Eventlet:
gunicorn --worker-class eventlet --workers 1 --bind 0.0.0.0:5000 --timeout 120 app:app
